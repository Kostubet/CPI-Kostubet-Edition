# Установка / Installation

[Русский](#русский) · [English](#english)

## Русский

### Перед установкой

Понадобятся рут-права, работающий LSPosed и системный лаунчер с оформлением иконок Flux.
Другие икон паки сейчас не поддерживаются.

Модуль находится в бета-тестировании. Проверялся только на ColorOS 17.
Поддерживаемые ветки - ColorOS17/OxygenOS17/RUI7; версия 16 почти не тестировалась.
Совместимость зависит от прошивки и версии системного лаунчера.

### Пошаговая установка

1. Скачайте APK из [релизов CPI Kostubet Edition](https://github.com/Kostubet/CPI-Kostubet-Edition/releases) и установите его.
2. Откройте CPI Kostubet Edition. Когда менеджер рут-доступа запросит разрешение, предоставьте его приложению. Если ранее отказали, откройте свой менеджер рут-доступа и разрешите доступ для CPI Kostubet Edition.
3. Откройте LSPosed, найдите CPI Kostubet Edition в списке модулей и включите его.
4. Выберите системный лаунчер в области действия модуля. Для уведомлений, громкости и экрана блокировки выберите также **System UI**.
5. В системных настройках оформления иконок выберите **Flux**.
6. Вернитесь в CPI Kostubet Edition и включите основной переключатель модуля. Включите размытие фона и выберите Frosted или Liquid Glass.
7. Откройте меню перезапуска во вкладке «Функции» и перезапустите лаунчер. Если меняли область действия System UI, перезапустите и его.

### Если что-то работает неправильно

1. Проверьте, что CPI Kostubet Edition получил рут-доступ в вашем менеджере рут-прав.
2. Проверьте включение модуля и правильный лаунчер в области действия LSPosed.
3. Убедитесь, что выбран Flux и включён основной переключатель CPI Kostubet Edition.
4. Перезапустите лаунчер кнопкой внутри CPI Kostubet Edition после изменения области действия или настроек.
5. Если установили обновление поверх старой сборки, проверьте режим размытия в настройках. Live обновляет материал во время движения; сохранённый выбор Static при обновлении остаётся прежним.

Если проблема сохраняется, [сообщите о ней в Kostubet Topics](https://t.me/KostubetTopics).
Укажите модель телефона, версию прошивки, версию системного лаунчера и CPI Kostubet Edition,
а также шаги для повторения проблемы. По возможности приложите запись экрана и диагностический лог из настроек модуля.

## English

### Before installation

You need root access, a working LSPosed installation and the system launcher with the Flux icon style.
Other icon packs are not currently supported.

The module is in beta testing and has only been tested on ColorOS 17.
Supported branches are ColorOS17/OxygenOS17/RUI7; version 16 has barely been tested.
Compatibility depends on the firmware and system launcher version.

### Step-by-step installation

1. Download the APK from [CPI Kostubet Edition releases](https://github.com/Kostubet/CPI-Kostubet-Edition/releases) and install it.
2. Open CPI Kostubet Edition. Grant the app root access when your root manager asks. If you denied it previously, open your root manager and allow root access for CPI Kostubet Edition.
3. Open LSPosed, find CPI Kostubet Edition in the module list and enable it.
4. Select your installed system launcher and CPI Kostubet Edition in the module scope. Select the launcher you actually use.
5. Choose **Flux** in the system icon style settings.
6. Return to CPI Kostubet Edition and enable the main module switch. Enable background blur and select Frosted or Liquid Glass.
7. Use the launcher restart button on the CPI Kostubet Edition home screen. Wait for the home screen to return.

### If something does not work correctly

1. Check that your root manager has granted root access to CPI Kostubet Edition.
2. Check that the module is enabled and the correct launcher is selected in LSPosed.
3. Make sure Flux is selected and the main CPI Kostubet Edition switch is enabled.
4. Restart the launcher using the button inside CPI Kostubet Edition after changing the scope or settings.
5. If you updated an older build, check the blur mode in settings. Live updates the material during motion; an explicitly saved Static selection is preserved during updates.

If the issue persists, [report it in Kostubet Topics](https://t.me/KostubetTopics).
Include your phone model, firmware version, system launcher version, CPI Kostubet Edition version
and steps to reproduce the issue. If possible, attach a screen recording and a diagnostic log from the module settings.
